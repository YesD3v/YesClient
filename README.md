# YesClient

**YesClient** is a Minecraft utility and client-side mod primarily built for **Hypixel Housing** (`hypixel.net/housing`).

It provides a collection of building utilities, quality-of-life features, visual modules, combat utilities, and various experimental/exploit-oriented modules.

> **Version:** 1.0.6
> **Primary Use:** Hypixel Housing
> **Platform:** Minecraft Forge

## Installation

1. Install the required Minecraft version and **Forge**.
2. Download the latest YesClient `.jar`.
3. Open your Minecraft directory:

   * Windows: `%APPDATA%\.minecraft`
4. Open the `mods` folder.
5. Place the YesClient `.jar` inside the folder.
6. Launch Minecraft using the Forge profile.

## Usage

Once Minecraft is launched, open the YesClient ClickGUI using the configured keybind.

Modules can be enabled or disabled individually, with most settings configurable directly through the client.

## Hypixel Housing

YesClient is primarily designed around **Hypixel Housing**, with features intended to assist with:

* Building and editing
* Housing utilities
* Player detection
* Visual information
* NBT manipulation
* Inventory management
* Quality-of-life improvements
* Freebuild workflows
* Housing-specific experimentation

Some modules may interact with game mechanics or packets in ways that can be restricted by servers.
