YesClient Installation
Follow these steps after downloading YesClient.
1
Download Forge 1.8.9
Download the latest available Forge 1.8.9 installer from the official Forge page.
Download Forge 1.8.9
2
Run the Forge installer
Open the Forge installer you downloaded and select Install client. Let the installer finish.
3
Select the Forge profile
Open the Minecraft Launcher and select the newly installed Forge 1.8.9 profile.
4
Open the Minecraft mods folder
Before launching Minecraft, press Win + R, paste the command below, and press Enter.
%appdata%\.minecraft\mods
If the mods folder does not exist, create a folder named mods inside .minecraft.
5
Move YesClient into the mods folder
Take the downloaded YesClient-1.1.0.jar file and place it inside the mods folder.
6
Launch Minecraft
Return to the Minecraft Launcher and launch the Forge 1.8.9 profile.
