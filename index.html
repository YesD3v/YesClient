Install

  1. Get Forge 1.8.9

    Download the Forge 1.8.9 installer from the official Forge site.

    Open the Forge 1.8.9 downloads

  2. Run the installer

    Open it, choose Install client, and let it finish.

  3. Select the Forge profile

    In the Minecraft Launcher, pick the new Forge 1.8.9 profile.

  4. Open your mods folder

  5. Add YesClient

    Move the downloaded .jar file into the mods folder.

  6. Launch Minecraft

    Start the Forge 1.8.9 profile from the launcher.
